## One change I strongly recommend for your UI

For **your specific project**, I would make the rabbit **not just an image**.

Make it a **stateful Canvas component**.

The architecture should be:

```text
                    EMORA CORE
                       │
              Canvas + JavaScript
                       │
       ┌───────────────┼────────────────┐
       │               │                │
       ▼               ▼                ▼
     STATE           EMOTION         AUDIO
       │               │                │
       ▼               ▼                ▼
 LISTENING          HAPPY           WAVEFORM
 THINKING           SAD             PULSE
 SPEAKING           ANGRY           RINGS
 SCANNING           NEUTRAL         PARTICLES
```

That's exactly the kind of thing Streamlit Components V2 is designed for: complex interactive UI, JavaScript, state, triggers, and Python↔browser communication. ([Streamlit Docs][1])

### I would **not** add React right now

For your current project, I'd use:

**Python**
→ Streamlit
→ FastAPI

**Frontend component**
→ HTML
→ CSS
→ Vanilla JavaScript
→ Canvas
→ SVG
→ Web APIs

That is enough.

If later the rabbit becomes much more complex and you need dozens of interactive frontend states, then a package-based Components V2 implementation with **TypeScript** becomes worthwhile. Streamlit's current documentation specifically recommends package-based components when you need TypeScript, external npm dependencies, build optimization, or more complex logic. ([Streamlit Docs][3])
